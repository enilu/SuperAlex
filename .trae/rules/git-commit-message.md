# Git 提交信息规范

## 格式要求

提交信息仅保留**单行摘要**，不写子项内容。

### 格式

```text
<类型>: <简短描述>
```

### 类型说明

- **feat**: 新增功能或游戏
- **fix**: 修复bug
- **docs**: 更新文档
- **style**: 代码格式调整（不影响功能）
- **refactor**: 代码重构
- **test**: 添加/修改测试

### 示例

```text
feat: 添加颜色配对乐园游戏
fix: 修复PinyinMatch弹窗自动弹出问题
docs: 更新README游戏列表
style: 优化首页卡片样式
```

## 注意事项

- 描述使用中文，简洁明了（不超过50字）
- 首字母小写，结尾不加标点
- 不写详细变更列表，仅保留摘要
