# 三国演义知识闯关 H5 小游戏

一个面向7岁儿童的三国演义知识闯关H5小游戏，通过趣味问答的方式帮助孩子巩固三国知识。

![三国演义](favicon.svg)

## 项目简介

本项目是一个纯前端H5小游戏，采用模块化架构设计，无需后端支持。游戏包含4个关卡，每关随机抽取5道题目，支持拼音显示、复活机制、题库管理等功能，适合亲子共玩。

## 核心特性

- **闯关模式**：4个关卡，每关5题，答对3题过关
- **复活机制**：每关1次复活机会，提供关键词提示
- **拼音支持**：题目显示汉语拼音，帮助认字不多的儿童
- **题库管理**：家长可通过界面添加、编辑、删除题目
- **进度保存**：本地存储游戏进度和成就
- **音效系统**：答对答错音效反馈
- **荣誉证书**：通关后可获得"三国小达人"电子证书
- **响应式设计**：适配各种屏幕尺寸

## 技术栈

- **前端**：纯 HTML5 + CSS3 + ES6 JavaScript
- **架构**：模块化设计，无框架依赖
- **存储**：LocalStorage 本地存储
- **音效**：Web Audio API

## 游戏设计

### 适合年龄
- 7岁儿童（贴合孩子认知，避免复杂文字、深奥情节）

### 游戏时长
- 15-20分钟（每关约5分钟）

### 关卡设计

| 关卡 | 名称 | 题目数量 | 考核重点 |
|------|------|----------|----------|
| 1 | 人物小达人 | 50题(选5) | 核心人物识别 |
| 2 | 情节小能手 | 50题(选5) | 经典故事情节 |
| 3 | 道具配对师 | 50题(选5) | 人物武器配对 |
| 4 | 趣味小问答 | 50题(选5) | 综合趣味知识 |

### 闯关规则

1. 每关5道三选一选择题
2. 答对3道及以上闯关成功，自动解锁下一关
3. 答对不足3道可使用1次复活机会
4. 复活提供关键词提示，帮助找到答案
5. 通关全部4关可获得"三国小达人"荣誉证书

## 功能说明

### 题库管理

家长可以通过"题库管理"功能：

1. **查看题目**：浏览所有题目，按关卡筛选
2. **添加题目**：填写题目内容、选项、答案、提示关键词
3. **编辑题目**：修改已有题目内容
4. **删除题目**：删除不需要的题目

题目格式：
- 题目内容：问题的文字描述
- 选项：A/B/C 三个选项
- 正确答案：A、B 或 C
- 所属关卡：选择对应关卡
- 提示关键词：复活时显示的提示

### 设置选项

- **音效开关**：开启/关闭答题音效
- **背景音乐**：开启/关闭背景音乐
- **重置进度**：清除所有游戏进度

## 技术亮点

### 模块化架构
```javascript
// 各模块职责清晰
- app.js: 应用初始化
- config.js: 游戏配置和题库
- questionManager.js: 题库CRUD操作
- gameManager.js: 游戏核心逻辑
- progressManager.js: 进度持久化
- audioManager.js: 音效播放
- cacheManager.js: 缓存管理
- uiManager.js: 界面交互
```

### 随机题目抽取
使用 Fisher-Yates 洗牌算法从50题中随机抽取5题，确保每次游戏题目不同。

### 本地化存储
使用 LocalStorage 存储进度、设置和自定义题目，无需后端支持。

### 古风UI设计
- 金红色渐变背景
- 卡片式界面布局
- 平滑动画过渡
- 响应式适配

## 题库更新指南

### 录入新题

1. 点击"题库管理"
2. 切换到"添加题目"标签
3. 填写以下信息：
   - 题目内容
   - 选项A/B/C
   - 正确答案
   - 所属关卡
   - 提示关键词（可选）
4. 点击"保存"

### 更新注意事项

- 保持与原题难度一致
- 贴合7岁儿童认知水平
- 避免生僻词汇和复杂表达
- 选项设置避免混淆性过强
- 建议每次新增3-5题即可

## 家长指南

### 游戏前准备

1. 向孩子解释游戏规则
2. 确认孩子已阅读相关三国内容
3. 设置合适的游戏时长

### 游戏中引导

1. 不催促、不提示答案
2. 无论对错都给予鼓励
3. 复活环节可适当提示
4. 控制游戏时长，避免疲劳

### 游戏后延伸

1. 复盘错题，讲解相关故事
2. 根据进度更新题库
3. 可设置小奖励激励
4. 结合阅读深化理解

## 常见问题

**Q: 题目可以自定义吗？**
A: 可以，通过"题库管理"功能添加、编辑、删除题目。

**Q: 游戏进度会丢失吗？**
A: 进度保存在浏览器本地存储中，清除浏览器数据会导致进度丢失。

**Q: 可以在手机上玩吗？**
A: 可以，游戏采用响应式设计，适配各种屏幕尺寸。

**Q: 如何重置游戏进度？**
A: 在"设置"界面点击"重置进度"按钮。
