# Kingdom3 选择题拼音功能

## 功能概述

为Kingdom3项目（三国演义知识闯关）中的选择题答案添加了拼音显示功能，帮助儿童识别汉字，提升学习体验。

## 功能特点

1. **汉字拼音配对**：每个选项按钮显示汉字和对应的拼音
2. **清晰排版**：拼音显示在汉字右侧并用括号包围
3. **智能匹配**：使用内置汉字拼音字典获取字符拼音
4. **兼容性强**：不影响现有功能，仅增强用户体验

## 技术实现

1. **新增辅助函数**：
   - `getSimplePinyinDict()` - 简化的汉字拼音字典
   - `getPinyinForText(text)` - 将汉字文本转换为拼音

2. **修改选项渲染**：
   - 更新 `showQuestion()` 函数，使选项按钮显示汉字和拼音
   - HTML结构：`选项文字<span class="option-pinyin">(pinyin)</span>`

3. **添加样式支持**：
   - `.option-pinyin` - 拼音样式（较小字体，灰色，斜体）
   - 确保拼音正确显示在选项文字旁边

## 用户体验

- 儿童可以通过拼音帮助认识汉字
- 提升识字困难儿童的学习效果
- 保持了原有的交互逻辑和界面美观

## 适用场景

- 三国演义知识闯关的所有选择题
- 适合年龄较小或识字量较少的儿童
