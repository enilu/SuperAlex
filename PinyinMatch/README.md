# 拼音配对乐园

一个轻量、低门槛、适合幼儿园到小学低年级的拼音启蒙小游戏。

## 玩法

1. 选择难度（幼儿园 / 一年级 / 二年级）。
2. 点击“开始新一局”。
3. 先点左侧一个汉字，再点右侧对应拼音。
4. 全部配对完成即胜利。

## 特性

- 纯前端、零依赖、打开即玩
- 单局 1 分钟左右，节奏轻快
- 连击加分、答错轻惩罚，鼓励式反馈
- localStorage 保存历史最高分与对局统计
- 支持浏览器语音朗读汉字（若浏览器支持 `speechSynthesis`）
