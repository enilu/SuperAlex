# SuperAlex - 儿童教育小游戏集

> 为小朋友开发的寓教于乐小游戏集合

![SuperAlex](https://img.shields.io/badge/SuperAlex-v1.0.0-brightgreen)

## 项目简介

SuperAlex 是我为家里小朋友制作的一系列教育小游戏项目，旨在通过轻松有趣的方式帮助孩子们学习成长。每个游戏都是独立的 Web 应用，无需安装即可直接运行。

### 现有游戏

| 游戏 | 简介 | 状态 |
|------|------|------|
| 🌅 晨光冲锋队 | 帮助孩子建立良好晨间习惯的激励游戏 | ✅ 已完成 |
| ➕➖ 20以内加减法 | 数学基础运算练习游戏 | ✅ 已完成 |

## 项目展示

### 🌅 晨光冲锋队

一个为儿童晨间流程打造的轻量级激励游戏。通过任务引导、音效反馈与成就体系，帮助孩子养成良好的时间管理习惯，同时降低家长的催促压力。

**主要功能：**
- 任务倒计时与状态提示
- 自定义任务流程配置
- 成就系统与勋章展示
- 数据统计（闪电完成次数、连续天数）
- 多种音效包切换

**技术栈：** HTML5 + CSS3 + 原生 JavaScript + Web Audio API

**演示地址：** http://superalex.enilu.cn/

**目录：** `MornGo/`

---

### ➕➖ 20以内加减法

帮助小朋友练习20以内加减法运算的趣味数学游戏。

**主要功能：**
- 加法、减法、混合三种运算模式
- 选择题和填空题两种答题方式
- 每题15秒倒计时挑战
- 实时分数与进度统计
- 星级评价系统

**技术栈：** HTML5 + CSS3 + 原生 JavaScript

**目录：** `math20/`

## 快速开始

### 方式一：本地直接运行

1. 克隆或下载项目
```bash
git clone https://github.com/yourusername/SuperAlex.git
cd SuperAlex
```

2. 进入具体游戏目录
```bash
# 晨光冲锋队
cd MornGo

# 或 20以内加减法
cd math20
```

3. 双击 `index.html` 即可在浏览器中运行

### 方式二：使用本地服务器（推荐）

由于浏览器安全策略，部分功能在非 HTTP 服务下可能受限，推荐使用本地服务器：

**使用 Node.js：**
```bash
npx serve .
# 或
npx http-server -c-1 .
```

**使用 Python：**
```bash
python -m http.server 8080
```

## 技术特点

- **零依赖**：所有游戏均使用原生 JavaScript，无需任何框架
- **响应式设计**：适配手机、平板、桌面设备
- **本地存储**：使用 localStorage 保存游戏进度与设置
- **模块化代码**：清晰的代码结构，易于维护和扩展
- **友好交互**：专为儿童设计的简洁界面和操作流程
