# SuperAlex - 儿童教育小游戏集

> 为小朋友开发的寓教于乐小游戏集合

![SuperAlex](https://img.shields.io/badge/SuperAlex-v1.1.0-brightgreen)
![License](https://img.shields.io/badge/license-MIT-blue)

## 项目简介

SuperAlex 是一个面向幼儿园和小学阶段孩子的轻量 Web 教育游戏合集。每个游戏都是独立静态应用，零依赖、开箱即玩。

### 现有游戏

| 游戏 | 简介 | 状态 |
|------|------|------|
| 🌅 晨光冲锋队 | 帮助孩子建立良好晨间习惯的激励游戏 | ✅ 已完成 |
| ➕➖ 数学运算练习 | 数学基础运算练习游戏（支持20/100以内） | ✅ 已完成 |
| 📜 唐诗小当家 | 唐诗诵读、闯关与复习一体化学习游戏 | ✅ 已完成 |
| 🏯 三国演义知识闯关 | 三国人物与故事知识问答闯关 | ✅ 已完成 |
| 🔤 拼音配对乐园 | 低龄拼音配对启蒙小游戏 | ✅ 已完成 |
| 🎨 颜色配对乐园 | 颜色认知配对益智游戏 | ✅ 已完成 |

## 新增游戏开发建议

项目已新增模板目录：`templates/light-game-template/`。

推荐流程：

1. 复制模板目录并重命名（例如 `HanziMatch/`）。
2. 修改 `index.html` 与 `assets/js/config.js` 中的游戏名称、题库和配置。
3. 在 `gameManager.js` 实现核心玩法（先 MVP，再扩展）。
4. 在根目录 `index.html` 添加入口卡片。
5. 在本 README 增加游戏说明。

## 项目展示

### 🌅 晨光冲锋队

培养晨间习惯的轻量激励游戏，包含任务倒计时、成就系统和音效反馈。

**目录：** `MornGo/`

### ➕➖ 数学运算练习

帮助孩子练习加减法运算，支持20以内和100以内两种难度，提供多种运算模式和答题方式。

**目录：** `math20/`

### 📜 唐诗小当家

通过诵读、闯关、复习模式学习唐诗，支持拼音与音频。

**目录：** `TangPoem/`

### 🏯 三国演义知识闯关

通过问答闯关认识三国人物和经典故事。

**目录：** `Kingdom3/`

### 🔤 拼音配对乐园

适合幼儿园到小学低年级：先点汉字，再点对应拼音完成配对。

**主要功能：**
- 三档难度（幼儿园 / 一年级 / 二年级）
- 倒计时配对、连击奖励
- 历史最高分与对局统计（localStorage）
- 浏览器语音朗读汉字（支持时启用）

**目录：** `PinyinMatch/`

### 🎨 颜色配对乐园

帮助小朋友认识颜色，找出相同颜色的卡片进行配对。

**主要功能：**
- 三档难度（简单 3对 / 中等 4对 / 困难 6对）
- 倒计时挑战、时间奖励分数
- 历史最高分与对局统计（localStorage）
- 10种鲜艳颜色，配有表情符号

**目录：** `ColorMatch/`

## 快速开始

### 方式一：本地直接运行

1. 克隆或下载项目
```bash
git clone https://github.com/yourusername/SuperAlex.git
cd SuperAlex
```

2. 启动本地服务（推荐）
```bash
# Node.js
npx serve .

# 或 Python
python -m http.server 8080
```

3. 在浏览器打开 `http://127.0.0.1:8080`

### 📌 推荐开发优先级

**第一优先级（简单易开发）：**
1. 颜色配对 - 基础交互，逻辑简单
2. 形状配对 - 与颜色配对类似，可复用框架
3. 动物叫声配对 - 趣味强，容易吸引小朋友

**第二优先级（教育价值高）：**
4. 汉字连连看 - 帮助识字
5. 单词图片配对 - 英语启蒙
6. 记忆力大挑战 - 锻炼记忆力

**第三优先级（趣味性强）：**
7. 迷宫冒险 - 可玩性高
8. 拼图游戏 - 经典益智游戏
9. 找不同 - 观察力训练

---

### 🛠️ 开发建议

1. **复用模板**：使用 `templates/light-game-template/` 作为基础框架
2. **保持轻量**：每个游戏独立，避免引入复杂依赖
3. **儿童友好**：颜色鲜艳、按钮较大、反馈及时
4. **循序渐进**：先实现MVP版本，再逐步扩展功能
5. **数据持久化**：使用 localStorage 保存游戏进度和成就

## 技术特点

- **零依赖**：所有游戏均使用原生 JavaScript
- **响应式设计**：适配手机、平板、桌面设备
- **本地存储**：使用 localStorage 保存进度和统计
- **模块化代码**：`config + app + manager` 模式易扩展
- **儿童友好**：正向反馈、短时长、低操作门槛

## AI Agent Guide（统一入口）

### 执行顺序

1. 先读本 README 的关键章节（项目结构、运行方式、约束）
2. 扫描并命中 `doc/ai/skills/` 的 `SKILL.md`
3. 如适用，复用 `doc/ai/prompts/`
4. 最后读取工具入口差异项（如 `AGENTS.md`、`CLAUDE.md`）

### 协作与交互约束（高优先级）

- 代码注释与文档默认使用中文
- 编写任何代码前，先描述实现方法并等待用户批准
- 需求有歧义时，先澄清再实施
- 预估改动超过 3 个文件时，先拆分子任务再继续
- 改动保持最小必要，不做无需求的大规模重构
- 涉及 localStorage 键名或数据结构变更时，必须说明兼容与迁移影响
- 每轮交互结束后，会话沉淀到 `doc/ai/sessions/yyyyMMdd/<git-user>.md`
- 最终回复前，必须先完成会话落盘，并执行校验
- 最终回复需包含：`会话落盘：已完成/失败 + 文件路径 + 时间戳`

### 通用实施与输出规范

- 搜索与定位优先使用 `rg` / `rg --files`；环境未安装时，使用系统可用的等效工具
- 优先复用现有模式（静态页面 + 原生 JS + manager 模式）
- 较大改动先给简短计划，再分步落地
- 验证至少覆盖与改动直接相关的最小检查
- 无法验证时，明确原因、风险与影响范围
- 复杂任务计划文档统一放在 `doc/superpowers/plans/`

### AI 资产目录

| 目录 | 用途 |
|------|------|
| `doc/ai/skills/` | 项目内 Skill 真源目录（common/codex/claude/opencode） |
| `doc/ai/prompts/` | 项目内 Prompt 真源目录（project/tech/business/templates） |
| `doc/ai/sessions/` | 会话沉淀目录（按日期/用户归档） |
| `doc/superpowers/plans/` | 复杂任务的实施计划目录 |

### 冲突优先级

1. `README.md`（公共规则唯一真源）
2. 命中的 `doc/ai/skills/**/SKILL.md`
3. 命中的 `doc/ai/prompts/**`
4. 工具入口文件（`AGENTS.md`、`CLAUDE.md`）

> 工具入口文件与 README 冲突时，以 README 为准
