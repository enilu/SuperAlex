# 唐诗数据管理指南

## 数据文件结构

```
TangPoem/assets/data/
├── poems.json          # 唐诗索引文件（必须）
└── poems/             # 唐诗数据目录
    ├── 001.json       # 第1首唐诗
    ├── 002.json       # 第2首唐诗
    ├── 003.json       # 第3首唐诗
    └── ...            # 更多唐诗
```

## 如何添加新唐诗

### 步骤1：创建唐诗数据文件

在 `assets/data/poems/` 目录下创建新的 JSON 文件，建议使用三位数编号：
- 001.json, 002.json, 003.json, ...

### 步骤2：填写唐诗数据

每首唐诗的数据格式如下：

```json
{
    "id": 1,
    "title": "静夜思",
    "author": "李白",
    "dynasty": "唐",
    "grade": "小学一年级",
    "content": [
        { "text": "床前明月光", "pinyin": "chuáng qián míng yuè guāng" },
        { "text": "疑是地上霜", "pinyin": "yí shì dì shàng shuāng" },
        { "text": "举头望明月", "pinyin": "jǔ tóu wàng míng yuè" },
        { "text": "低头思故乡", "pinyin": "dī tóu sī gù xiāng" }
    ],
    "annotation": "霜：指地上像霜一样的月光",
    "translation": "明亮的月光洒在井栏上，好像地上结了一层霜。抬起头看天上的明月，低下头思念自己的故乡。",
    "audio": "assets/audio/recite/001.mp3"
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | number | 是 | 唐诗唯一编号 |
| title | string | 是 | 唐诗标题 |
| author | string | 是 | 作者名称 |
| dynasty | string | 是 | 朝代 |
| grade | string | 是 | 适合年级（如：小学一年级） |
| content | array | 是 | 诗词内容，每句包含 text 和 pinyin |
| annotation | string | 否 | 注释说明 |
| translation | string | 是 | 译文 |
| audio | string | 否 | 诵读音频路径 |

### 步骤3：更新索引文件

在 `assets/data/poems.json` 中添加新唐诗的索引信息：

```json
{
    "version": "1.0.0",
    "lastUpdate": "2026-02-15",
    "totalCount": 6,
    "poems": [
        {
            "id": 1,
            "file": "001.json",
            "title": "静夜思",
            "author": "李白",
            "grade": "小学一年级"
        },
        {
            "id": 6,
            "file": "006.json",
            "title": "新唐诗标题",
            "author": "作者名",
            "grade": "小学二年级"
        }
    ]
}
```

**重要：**
- `totalCount` 需要更新为实际唐诗总数
- 确保每首唐诗的 `id` 和 `file` 字段对应正确

## 常见唐诗资源

你可以从以下渠道获取唐诗数据：
- 小学语文教材
- 唐诗三百首
- 古诗文网

## 拼音标注规则

- 使用标准汉语拼音
- 声调符号：ā á ǎ à ē é ě è ī í ǐ ì ō ó ǒ ò ū ú ǔ ù
- 轻声不标调
- 大写专有名词首字母（如人名、地名）

## 音频资源

诵读音频文件放置在 `assets/audio/recite/` 目录下：
- 文件命名：001.mp3, 002.mp3, ...
- 格式：MP3
- 建议比特率：128kbps

## 测试

添加新唐诗后，刷新游戏页面测试：
1. 打开诵读模式，查看新唐诗是否显示
2. 进入闯关模式，确保能正确生成题目
3. 测试拼音和译文显示是否正确

## 批量导入

如果需要批量导入多首唐诗，可以编写脚本自动生成 JSON 文件。
