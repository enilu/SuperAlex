# 唐诗小当家 - 基于艾宾浩斯遗忘曲线的复习模式设计

## 概述

本设计文档详细阐述了唐诗小当家游戏复习模式的改进方案。当前复习模式采用简单的2天固定间隔，本次改进将引入**艾宾浩斯遗忘曲线**理论，结合**儿童学习特点**，设计一套科学、个性化的复习系统，帮助儿童更有效地巩固唐诗记忆。

## 设计目标

1. **科学性**：基于艾宾浩斯遗忘曲线理论，在最容易遗忘的时间点进行复习
2. **个性化**：根据每个儿童的学习表现动态调整复习计划
3. **儿童友好**：考虑儿童注意力特点，设计适宜的复习强度和频率
4. **趣味性**：保持游戏化元素，避免复习变得枯燥
5. **家长可控**：提供适当的家长设置选项，控制学习强度
6. **向后兼容**：平滑迁移现有用户数据，不丢失学习进度

## 儿童学习特点考虑

| 特点 | 设计应对策略 |
|------|--------------|
| **注意力持续时间短** (5-15分钟) | 单次复习限制在5-10分钟内，每次复习3-5首唐诗 |

| **家长参与需求** | 提供复习报告和家长设置页面 |

## 艾宾浩斯遗忘曲线原理

德国心理学家艾宾浩斯研究发现，记忆遗忘遵循先快后慢的规律：

```
记忆保留率随时间变化曲线：
┌─────────────────────────────────────────────┐
│ 20分钟后 → 遗忘42% → 保留58%                │
│ 1小时后   → 遗忘56% → 保留44%                │
│ 9小时后   → 遗忘64% → 保留36%                │
│ 1天后     → 遗忘66% → 保留34%                │
│ 2天后     → 遗忘72% → 保留28%                │
│ 6天后     → 遗忘75% → 保留25%                │
│ 31天后    → 遗忘79% → 保留21%                │
└─────────────────────────────────────────────┘
```

**关键复习时间点**：在遗忘发生前进行复习，可以大幅提升记忆保留率。

## 复习间隔设计（儿童友好版）

针对3-12岁儿童的学习特点，调整标准艾宾浩斯间隔：

| 复习阶段 | 标准间隔 | 儿童友好间隔 | 说明 |
|----------|----------|--------------|------|
| **第1次复习** | 20分钟 | **5分钟** | 儿童注意力短，趁热打铁 |
| **第2次复习** | 1小时 | **30分钟** | 适度延后，巩固短期记忆 |
| **第3次复习** | 9小时 | **3小时** | 当天内完成第三次复习 |
| **第4次复习** | 1天 | **1天** | 隔天强化记忆 |
| **第5次复习** | 2天 | **3天** | 适当延长，检验记忆持久性 |
| **第6次复习** | 6天 | **1周** | 周度复习 |
| **第7次复习** | 31天 | **2周** | 双周复习 |
| **第8次复习** | - | **1个月** | 月度总复习 |
| **长期维持** | - | **3个月** | 季度复习（完全掌握后） |

**动态调整机制**：
- 答对率≥80%：按标准间隔进行下一阶段
- 答对率60-79%：保持当前阶段，缩短下次间隔20%
- 答对率<60%：退回上一阶段，重新开始该阶段

## 记忆强度计算算法

### 1. 记忆强度（Memory Strength）概念
替代当前的`mastery`字段，采用0-100的连续值，表示对该首唐诗的记忆牢固程度。

### 2. 强度计算公式
```
新强度 = 原强度 + Δ强度 - 遗忘衰减

其中：
Δ强度 = 基础增益 × 表现系数 × 阶段系数
遗忘衰减 = 时间衰减系数 × (距离上次复习天数)
```

### 3. 具体参数

| 参数 | 值 | 说明 |
|------|-----|------|
| **基础增益** | 30 | 每次复习的基本强度增加 |
| **表现系数** | 0.6-1.4 | 根据答对率调整（60%→0.6，100%→1.4） |
| **阶段系数** | 0.8-1.2 | 早期阶段增益高，后期增益低 |
| **时间衰减系数** | 1.5 | 每天衰减的强度值 |

### 4. 强度等级划分

| 强度范围 | 等级 | 颜色 | 说明 |
|----------|------|------|------|
| 0-20 | 陌生 | 🔴 | 刚接触，基本不会 |
| 21-50 | 熟悉 | 🟠 | 有点印象，但不牢固 |
| 51-70 | 掌握 | 🟡 | 基本掌握，偶尔出错 |
| 71-85 | 熟练 | 🟢 | 熟练背诵，很少出错 |
| 86-100 | 精通 | 🔵 | 完全掌握，长期记忆 |

### 5. 掌握判定
当记忆强度≥85且完成第5次复习（1周后），标记为`mastered: true`，进入**长期维持**阶段（每3个月复习一次）。

### 数据迁移策略
1. **版本检测**：在`CacheManager`中检测缓存版本
2. **自动迁移**：发现旧版数据结构时自动转换
3. **字段映射**：
   - `mastery` → `memoryStrength`（直接复制）
   - 根据`lastReviewTime`和`mastery`估算`reviewStage`
   - 计算`nextReviewTime`（基于当前时间+默认间隔）

## 核心算法实现

### 1. 复习计划生成算法
```javascript
function generateReviewPlan() {
    const now = new Date();
    const duePoems = [];

    Object.entries(progressData).forEach(([poemId, progress]) => {
        if (progress.memoryStrength >= 85 && progress.reviewStage >= 7) {
            // 已掌握，进入长期维持阶段
            if (progress.nextReviewTime && new Date(progress.nextReviewTime) <= now) {
                duePoems.push(poemId);
            }
        } else if (progress.nextReviewTime && new Date(progress.nextReviewTime) <= now) {
            // 常规复习阶段
            duePoems.push(poemId);
        }
    });

    // 按记忆强度排序（强度越低越优先）
    return duePoems.sort((a, b) =>
        progressData[a].memoryStrength - progressData[b].memoryStrength
    ).slice(0, CONFIG.REVIEW_CONFIG.REVIEW_SETTINGS.MAX_POEMS_PER_SESSION);
}
```

### 2. 复习结果处理算法
```javascript
function processReviewResult(poemId, correctRate) {
    const progress = progressData[poemId];
    const stage = progress.reviewStage;
    const intervals = CONFIG.REVIEW_CONFIG.INTERVALS;

    // 1. 计算记忆强度变化
    const baseGain = CONFIG.REVIEW_CONFIG.MEMORY_STRENGTH.BASE_GAIN;
    const perfFactor = mapCorrectRateToFactor(correctRate);
    const stageFactor = CONFIG.REVIEW_CONFIG.MEMORY_STRENGTH.STAGE_FACTORS[stage];

    const strengthGain = baseGain * perfFactor * stageFactor;
    const daysSinceLastReview = getDaysSince(progress.lastReviewTime);
    const decay = CONFIG.REVIEW_CONFIG.MEMORY_STRENGTH.DECAY_RATE * daysSinceLastReview;

    progress.memoryStrength = Math.max(0, Math.min(100,
        progress.memoryStrength + strengthGain - decay
    ));

    // 2. 确定下一阶段
    let nextStage = stage;
    let intervalMultiplier = 1.0;

    if (correctRate >= CONFIG.REVIEW_CONFIG.ADJUSTMENT_RULES.PROMOTE_THRESHOLD) {
        nextStage = Math.min(stage + 1, intervals.length - 1);
    } else if (correctRate < CONFIG.REVIEW_CONFIG.ADJUSTMENT_RULES.DEMOTE_THRESHOLD) {
        nextStage = Math.max(stage - 1, 0);
        intervalMultiplier = 1 - CONFIG.REVIEW_CONFIG.ADJUSTMENT_RULES.INTERVAL_ADJUSTMENT;
    } else {
        // 保持当前阶段，调整间隔
        intervalMultiplier = 1 - CONFIG.REVIEW_CONFIG.ADJUSTMENT_RULES.INTERVAL_ADJUSTMENT;
    }

    // 3. 计算下次复习时间
    const intervalMinutes = intervals[nextStage] * intervalMultiplier;
    progress.nextReviewTime = new Date(Date.now() + intervalMinutes * 60000).toISOString();
    progress.reviewStage = nextStage;

    // 4. 更新历史记录
    progress.reviewHistory.push({
        timestamp: new Date().toISOString(),
        stage: stage,
        correctRate: correctRate,
        strengthChange: strengthGain - decay
    });

    // 5. 检查是否达到掌握标准
    if (progress.memoryStrength >= 85 && progress.reviewStage >= 5) {
        progress.mastered = true;
        progress.masteryDate = new Date().toISOString();
    }
}
```

### 3. 数据迁移算法
```javascript
function migrateProgressData(oldProgress) {
    const newProgress = {};

    Object.entries(oldProgress).forEach(([poemId, data]) => {
        // 计算初始复习阶段（基于最后复习时间）
        const daysSinceReview = getDaysSince(data.lastReviewTime);
        let estimatedStage = 0;

        if (daysSinceReview <= 0.1) estimatedStage = 0;      // 5分钟内
        else if (daysSinceReview <= 0.5) estimatedStage = 1; // 30分钟内
        else if (daysSinceReview <= 3) estimatedStage = 2;   // 3小时内
        else if (daysSinceReview <= 1) estimatedStage = 3;   // 1天内
        else if (daysSinceReview <= 3) estimatedStage = 4;   // 3天内
        else estimatedStage = 5;                            // 超过3天

        newProgress[poemId] = {
            // 保持兼容字段
            learned: data.learned,
            lastReviewTime: data.lastReviewTime,
            mastery: data.mastery,
            correctCount: data.correctCount,
            wrongCount: data.wrongCount,

            // 新字段
            memoryStrength: data.mastery,
            reviewStage: estimatedStage,
            nextReviewTime: calculateNextReviewTime(data.lastReviewTime, estimatedStage),
            totalReviews: data.correctCount + data.wrongCount,
            reviewHistory: [],
            masteryDate: data.learned ? data.lastReviewTime : null,
            easinessFactor: 2.5,
            consecutiveCorrect: 0
        };
    });

    return newProgress;
}
```
