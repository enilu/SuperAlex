# TangPoem 复习模式滚动问题修复

## 问题描述

在复习模式页面，当待复习的诗歌列表很长时，底部的"开始复习"按钮会移出可视区域，但页面没有滚动条，导致用户无法看到并点击该按钮。

## 问题原因

1. `.review-container` 没有设置适当的布局结构
2. `.review-card` 没有限制最大高度
3. 当内容超出屏幕高度时，没有滚动机制

## 解决方案

1. **修改容器布局**：
   - 将 `.review-container` 设置为 `flex-direction: column` 和 `min-height: calc(100vh - 80px)`
   - 添加 `gap: 1.5rem` 来保持元素间距

2. **限制卡片高度**：
   - 将 `.review-card` 的 `margin-bottom` 改为 `flex: 1` 以适应布局
   - 设置 `max-height: 60vh` 限制卡片最大高度
   - 启用 `overflow-y: auto` 以显示滚动条

3. **优化按钮样式**：
   - 将 `.start-review-btn` 设置为 `flex-shrink: 0` 防止按钮缩小
   - 设置 `align-self: center` 确保按钮居中
   - 添加 `max-width: 500px` 保持按钮尺寸一致

4. **增强滚动条样式**：
   - 为 `.review-list` 添加 `max-height: 50vh` 和 `overflow-y: auto`
   - 为滚动条设置了美观的自定义样式

## 效果

- 当待复习诗歌较多时，复习列表区域会出现滚动条
- 用户可以滚动查看所有待复习的诗歌
- "开始复习"按钮始终保持在可视区域内
- 提供了更好的用户体验
