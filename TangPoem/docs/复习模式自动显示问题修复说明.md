# TangPoem 复习模式自动显示问题修复

## 问题描述

修复了一个CSS样式冲突问题：页面加载时，复习模式会自动显示，而不是显示开始界面。

## 问题原因

在修改CSS样式以修复滚动问题时，错误地向 `#reviewScreen` 添加了 `display: flex` 属性：

```css
#reviewScreen {
    background: linear-gradient(135deg, #f093fb 0%, #f5576c 100%);
    display: flex;        /* 这行导致了问题 */
    flex-direction: column;
}
```

由于CSS特异性规则，ID选择器 (`#reviewScreen`) 的优先级高于类选择器 (`.screen`)，导致：
- `.screen` 设置的 `display: none` 被 `#reviewScreen` 中的 `display: flex` 覆盖
- 即使没有 `.active` 类，`#reviewScreen` 元素也会显示

## 解决方案

移除了 `#reviewScreen` 中的 `display: flex` 声明，保持原有的显示/隐藏控制机制：

```css
#reviewScreen {
    background: linear-gradient(135deg, #f093fb 0%, #f5576c 100%);
    flex-direction: column;  /* 保留布局相关属性 */
}
```

这样，显示/隐藏控制完全由 `.screen` 和 `.screen.active` 的样式控制：
- 默认情况下，所有屏幕（包括复习屏幕）都被隐藏
- 只有被添加 `.active` 类的屏幕才会显示

## 效果

- 修复了页面启动时自动显示复习模式的问题
- 应用现在正确地在启动时显示开始界面
- 屏幕切换功能恢复正常
- 滚动问题修复仍然有效
