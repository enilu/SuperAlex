# TangPoem 标记复习功能

## 功能概述

我们实现了在诵读模式中标记诗歌用于复习的功能，使用户可以主动选择想要复习的诗歌。

## 功能特点

1. **标记按钮**：在诵读模式的控制栏中添加了一个星形标记按钮
2. **状态显示**：按钮会根据当前诗歌是否被标记显示不同颜色
3. **即时生效**：标记的诗歌会立即出现在复习模式的待复习列表中
4. **持久化存储**：标记状态会被保存在本地缓存中
5. **双重复习机制**：既支持时间间隔自动复习，也支持用户主动标记复习

## 使用方法

1. 进入诵读模式
2. 浏览到你想标记的诗歌
3. 点击控制栏中的星形标记按钮
4. 被标记的诗歌会出现在复习模式的待复习列表中
5. 再次点击标记按钮可取消标记

## 技术实现

- 新增缓存类型：`MARKED_FOR_REVIEW`
- 新增函数：
  - `markPoemForReview(poemId)` - 标记诗歌
  - `unmarkPoemForReview(poemId)` - 取消标记
  - `isPoemMarkedForReview(poemId)` - 检查标记状态
  - `getMarkedPoemsForReview()` - 获取标记列表
- 修改 `getReviewPoems()` 函数，包含标记的诗歌
- 添加标记按钮的UI交互

## 用户体验

- 标记时显示成功通知
- 取消标记时显示取消通知
- 标记状态在切换诗歌时自动更新
- 复习计数会包含标记的诗歌
