# TangPoem 缓存管理增强功能

## 功能概述

本更新为TangPoem项目添加了更精细的缓存管理功能，包括：

1. 选择性清除缓存数据
2. 复习数据导出功能
3. 更好的数据分类管理

## 新增功能

### 1. 分类缓存管理

现在缓存被分为以下几类：

- **data**: 诗歌数据缓存（非用户数据）
- **progress**: 学习进度、成就、统计数据
- **settings**: 应用设置、音频设置
- **review**: 复习历史数据（新增）

### 2. 选择性清除功能

通过UI界面可以进行以下操作：

- **清除数据缓存**: 只清除诗歌数据，保留用户进度
- **清除学习进度**: 只清除学习进度、成就和统计数据
- **清除复习数据**: 只清除复习历史数据
- **清除所有缓存**: 清除所有数据（包括用户进度）

### 3. 数据导出功能

新增"导出复习数据"功能，可导出用户的复习进度数据用于备份。

## API扩展

### CacheManager新增方法

- `clearByCategory(category)`: 清除指定类别的缓存
- `clearAllExcept(categoriesToKeep)`: 清除除指定类别外的所有缓存
- `exportReviewData()`: 导出复习数据
- `importReviewData(data, merge)`: 导入复习数据

### 缓存类型新增

- `CacheType.REVIEW_HISTORY`: 复习历史数据缓存

## 使用场景

### 场景1：只想清理诗歌数据，保留学习进度
```javascript
CacheManager.clearByCategory('data');
```

### 场景2：只想清理学习进度，保留诗歌数据
```javascript
CacheManager.clearByCategory('progress');
```

### 场景3：清理所有除复习数据外的缓存
```javascript
CacheManager.clearAllExcept(['review']);
```

### 场景4：导出复习数据
```javascript
const reviewData = CacheManager.exportReviewData();
// 自动触发下载
```

## 界面更新

设置界面（齿轮图标）增加了以下按钮：
- 清除学习进度
- 清除复习数据
- 导出复习数据

## 迁移说明

此更新不影响现有数据结构，所有旧数据将继续正常工作。
