# 唐诗小当家 - 缓存管理系统使用说明

## 概述

缓存管理系统 (`cacheManager.js`) 提供统一的 localStorage 管理，支持版本控制和一键清除缓存功能。

## 系统架构

```
cacheManager.js  (缓存管理核心)
    ↓
    ├── poemManager.js    → 使用缓存存储诗歌数据
    ├── audioManager.js   → 使用缓存存储音频设置
    ├── progressManager.js → 使用缓存存储学习进度
    └── uiManager.js      → 提供设置界面清除缓存
```

## 缓存类型

| 类型 | 存储Key | 说明 | 用户数据 |
|------|---------|------|----------|
| `POEMS_DATA` | tangpoem_poems_data | 诗歌数据缓存 | 否 |
| `PROGRESS` | tangpoem_progress | 学习进度 | 是 |
| `ACHIEVEMENTS` | tangpoem_achievements | 成就数据 | 是 |
| `STATS` | tangpoem_stats | 统计数据 | 是 |
| `AUDIO_SETTINGS` | tangpoem_audio_settings | 音频设置 | 是 |
| `APP_SETTINGS` | tangpoem_app_settings | 应用设置 | 是 |

## API 使用

### 基本操作

```javascript
import { CacheManager, CacheType } from './cacheManager.js';

// 读取缓存
const poems = CacheManager.get(CacheType.POEMS_DATA);
const progress = CacheManager.get(CacheType.PROGRESS);

// 写入缓存
CacheManager.set(CacheType.POEMS_DATA, poemsData);
CacheManager.set(CacheType.PROGRESS, progressData);

// 删除指定缓存
CacheManager.remove(CacheType.POEMS_DATA);
```

### 清除缓存

```javascript
// 清除数据缓存（保留用户进度）
CacheManager.clearDataCache();

// 清除所有缓存（包括用户数据）
CacheManager.clearAllCache();

// 清除用户数据（保留数据缓存）
CacheManager.clearUserData();
```

### 缓存信息

```javascript
// 获取缓存统计信息
const info = CacheManager.getCacheInfo();
console.log(info);
// {
//   version: "1.0.0",
//   currentVersion: "1.0.0",
//   items: [...],
//   totalSize: 1234567
// }

// 格式化字节大小
const sizeStr = CacheManager.formatSize(1234567); // "1.18 MB"
```

### 备份/恢复

```javascript
// 导出缓存数据
const backup = CacheManager.exportCache(includeUserData = true);

// 导入缓存数据
CacheManager.importCache(backup, mergeUserData = true);
```

## 版本管理

### 版本配置

在 `cacheManager.js` 中配置版本号：

```javascript
const CURRENT_CACHE_VERSION = '1.0.0';  // 当前缓存版本
const MIN_COMPATIBLE_VERSION = '1.0.0'; // 最低兼容版本
```

### 版本升级策略

| 当前版本 | 新版本 | 行为 |
|----------|--------|------|
| 1.0.0 | 1.0.1 | 保留所有缓存 |
| 1.0.0 | 1.1.0 | 清除数据缓存，保留用户数据 |
| 1.0.0 | 2.0.0 | 清除所有缓存 |

### 部署时清除缓存

系统重新部署需要清除缓存时，按以下步骤操作：

1. **数据结构无变化** → 不需要更新版本号
2. **诗歌数据结构变化** → 升级 `CURRENT_CACHE_VERSION` 的次版本号 (如 1.0.0 → 1.1.0)
3. **进度数据结构变化** → 升级 `CURRENT_CACHE_VERSION` 的主版本号 (如 1.0.0 → 2.0.0)

## UI 界面使用

### 打开设置界面

在诵读模式界面点击右上角的 `⚙️` 设置按钮。

### 清除缓存选项

1. **清除数据缓存** - 仅清除诗歌数据等缓存文件，保留用户学习进度
2. **清除所有缓存** - 清除所有缓存包括用户进度、成就和统计数据

## 开发指南

### 添加新的缓存类型

1. 在 `CacheType` 枚举中添加新类型
2. 在 `CACHE_META` 中定义元数据
3. 使用 `CacheManager.get()` 和 `CacheManager.set()` 操作

```javascript
// 示例：添加新的设置类型
const CacheType = {
    // ...
    NEW_SETTING: 'new_setting'
};

const CACHE_META = {
    // ...
    [CacheType.NEW_SETTING]: {
        key: 'tangpoem_new_setting',
        default: {},
        isUserData: true,
        description: '新设置'
    }
};
```

## 注意事项

1. **初始化顺序**：`CacheManager.init()` 必须在其他模块使用缓存之前调用
2. **版本兼容**：数据结构变化时务必更新版本号
3. **用户数据**：清除操作会提示用户确认，避免误操作
4. **缓存大小**：诗歌数据缓存可能较大，建议定期清理

## 浏览器开发者工具

在浏览器控制台中可以直接调用：

```javascript
// 查看缓存信息
CacheManager.getCacheInfo()

// 手动清除缓存
CacheManager.clearDataCache()
CacheManager.clearAllCache()
```
