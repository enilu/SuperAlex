# TangPoem 选择题拼音功能

## 功能概述

为复习模式和闯关模式中的选择题添加了拼音显示功能，帮助儿童识别汉字，提升学习体验。

## 功能特点

1. **汉字拼音配对**：每个选项按钮同时显示汉字和对应的拼音
2. **清晰排版**：汉字和拼音在按钮上垂直排列，便于阅读
3. **智能匹配**：从诗歌原文中提取字符对应的拼音
4. **兼容性强**：不影响现有功能，仅增强用户体验

## 技术实现

1. **新增辅助函数**：
   - `getPinyinForCharacter(poem, character)` - 从诗歌内容中查找特定字符的拼音

2. **修改选项渲染**：
   - 更新 `showQuestion()` 函数，使选项按钮显示汉字和拼音
   - HTML结构：`<span class="option-char">汉</span><span class="option-pinyin">han</span>`

3. **添加样式支持**：
   - `.option-btn` - 设置为flex布局，垂直排列汉字和拼音
   - `.option-char` - 汉字样式（较大字体，加粗）
   - `.option-pinyin` - 拼音样式（较小字体，较低透明度）

## 用户体验

- 儿童可以通过拼音帮助认识汉字
- 提升识字困难儿童的学习效果
- 保持了原有的交互逻辑和界面美观

## 适用场景

- 闯关模式的填空题
- 复习模式的练习题
- 适合年龄较小或识字量较少的儿童
