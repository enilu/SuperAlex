# TangPoem 选择题拼音显示优化

## 功能概述

更新了复习模式和闯关模式中选择题的拼音显示方式，将拼音显示在汉字的右边并用括号括起来。

## 之前的样式
- 汉字和拼音垂直排列（拼音在汉字下方）

## 现在的样式
- 汉字和拼音水平排列（拼音在汉字右侧，用括号括起来）
- 例如：好(hǎo)，而不是上下排列的形式

## 技术实现

### CSS修改
- 将 `.option-btn` 从 `flex-direction: column` 改为 `inline-flex`，实现水平排列
- 调整了 `.option-pinyin` 的字体大小，使其更适合水平排列
- 设置 `gap: 0.5rem` 在汉字和拼音之间留出适当间距

### JavaScript修改
- 修改了选项生成代码，使拼音以 `(pinyin)` 格式显示
- 保持了原有的拼音检索逻辑

## 用户体验

- 选项更加紧凑，提高了界面整洁度
- 汉字和拼音的关系更清晰
- 保持了原有的交互逻辑和功能
