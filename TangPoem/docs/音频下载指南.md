- **主播**: 白云出岫、蓝色百合

- **步骤**:
  1. 在喜马拉雅APP或网站搜索专辑名称
  2. 下载需要的音频文件
  3. 按照上表重命名为对应编号

## 📂 自动整理脚本

### 使用方法

1. 将下载的音频文件放入临时文件夹
2. 运行整理脚本:
   ```bash
   node tools/organizeAudio.js <临时文件夹路径>
   ```

3. 脚本将自动:
   - 匹配音频文件与诗歌
   - 重命名为正确的格式
   - 移动到 assets/audio/recite/ 目录

## 💡 批量下载提示

由于音频资源版权保护，建议:

1. **优先下载重点诗词** (前30首)
