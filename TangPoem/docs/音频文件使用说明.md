# 唐诗音频文件使用说明

## 快速开始

### 第一步：下载音频

从以下推荐渠道下载唐诗朗诵音频：

#### 方法1：喜马拉雅（推荐）
1. 下载「喜马拉雅」APP或访问网站
2. 搜索专辑：「小学生必背古诗75+80首」
3. 选择需要的音频下载到本地

#### 方法2：免费在线收听
- **蜻蜓FM**: https://m.qingting.fm/vchannels/520937
- **Apple Podcasts**: 搜索「经典古诗词朗诵120首」

### 第二步：重命名和放置音频

将下载的音频文件重命名为对应编号，并放入指定目录：

| 诗歌ID | 标题 | 作者 | 目标文件名 |
|--------|------|------|-----------|
| 1 | 静夜思 | 李白 | 001.mp3 |
| 2 | 春晓 | 孟浩然 | 002.mp3 |
| 3 | 咏鹅 | 骆宾王 | 003.mp3 |
| ... | ... | ... | ... |

**存放位置**: `TangPoem/assets/audio/recite/`

详细90首诗歌列表请查看 `docs/音频下载指南.md`

### 第三步：游戏自动加载

音频文件就位后，游戏会自动加载对应诗歌的音频。

## 临时方案（音频未就绪时）

如果暂时没有音频文件，游戏会：
1. 跳过音频播放功能
2. 其他功能正常使用
3. 不影响诗词诵读和游戏功能

## 批量整理工具

如果您已经下载了大量音频文件，可以使用整理脚本：

```bash
# 使用整理脚本自动匹配和重命名
node tools/organizeAudio.js <音频文件夹路径>
```

该脚本会：
- 自动匹配音频文件与诗歌
- 重命名为正确的格式
- 移动到 assets/audio/recite/ 目录
