# AI Prompts 目录约定

本目录用于沉淀本项目内可复用的 Prompt 资产。

## 目标

- 把 `doc/ai/sessions/` 中已经验证有效的会话经验，提炼为可重复使用的 Prompt。
- 将单轮、轻流程、输入输出清晰的任务沉淀为 Prompt。
- 将多步骤、强依赖项目上下文和执行流程的任务继续沉淀到 `doc/ai/skills/`。

一句话判断：

- 单轮可复用，优先 Prompt。
- 多步骤可复用，优先 Skill。

## 目录结构

```text
doc/ai/prompts/
├── README.md
├── project/
├── tech/
├── business/
└── templates/
```

## 编写要求

每个 Prompt 文件建议包含以下部分：

1. 元数据
2. 目标
3. 适用场景
4. 输入要求
5. 上下文说明
6. 约束条件
7. 输出格式
8. Prompt 正文
9. 示例
10. 验收标准

## 沉淀建议

- 优先从真实会话中提炼，不直接复制整段对话。
- 删除一次性上下文，保留稳定结构。
- 如果 Prompt 反复依赖固定执行顺序、多个规范文件或检查脚本，应升级为 Skill。
