# 儿童教育小游戏开发技能

## 何时使用

- 新增或改造儿童教育小游戏功能。
- 评审游戏 UI、反馈机制、可玩性与儿童友好性。
- 需要快速检查是否符合幼儿园/小学阶段用户体验。

## 目标

- 统一儿童教育小游戏开发的受众定位、UI设计、玩法策略、技术实现与验收标准。
- 保证在保持轻量技术栈的前提下，获得明确、即时、正向的儿童交互反馈。

## 硬规则

- 默认面向 3-12 岁，设计必须区分年龄段难度。
- 单局时长优先控制在 1-2 分钟。
- 必须提供正向即时反馈（视觉变化 + 文案或音效）。
- 交互必须触摸友好，按钮和点击区优先大尺寸。
- 优先保持 `HTML5 + CSS3 + JavaScript + ES Modules + localStorage` 的轻量实现。

## 执行步骤

1. 先阅读 `references/development-guidelines.md`，对齐受众、UI、玩法和技术约束。
2. 方案落地前对照 `references/development-checklist.md` 逐项自检。
3. 若与项目级规则冲突，优先遵循 `README.md` 与 `common/project-shared`。
