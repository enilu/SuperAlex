# SuperAlex 项目通用技能

## 何时使用

- 任务发生在本仓库内。
- 当前任务只命中项目级约束，或其他领域 skill 仍需项目级兜底规则。

## 目标与边界

- 先对齐项目结构、模块职责、验证与交付基线，再落地最小必要改动。
- 本 skill 只提供项目级入口，不重复维护 README 中的完整公共规则。
- 会话落盘、Prompt 边界和计划目录等仓库级约束，以 `README.md` 的 `AI Agent Guide（统一入口）` 为唯一真源。

## 硬规则

- 变更保持小而聚焦，不混入无关重构。
- 优先复用现有模式，遵守静态页面 + 原生 JavaScript + manager 模式。
- 未明确要求破坏兼容时，不主动改变页面契约、路由层级、既有 localStorage 键名与数据结构。
- 涉及配置、缓存、题库结构、音频资源、权限或入口导航时，必须显式说明影响范围。
- 默认使用中文编写文档和必要注释，除非文件上下文已有明确英文约定。

## 先读哪里

- 项目公共规则以仓库 `README.md` 为准，优先回看：
  - 项目结构
  - 快速开始
  - AI Agent Guide（统一入口）
- 常见误判和遗漏项见 `references/gotchas.md`。

## 验证与交付

1. 优先做受影响模块的定向验证，不做无关全量命令。
2. 最终输出至少包含改动文件、验证命令与结果、未覆盖风险和影响范围。
