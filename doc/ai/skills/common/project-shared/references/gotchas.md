# 项目级 Gotchas

## 何时需要回看这份文件

- 任务看起来只是“小改动”，但可能牵涉入口首页、题库数据、缓存键或音频资源加载。
- 已经命中业务 skill，但不确定项目级交付和验证是否覆盖完整。

## 常见误判

- 只修改子游戏目录，不同步检查根目录 `index.html` 的入口链接和展示。
- 为了“顺手整理”做无关重构，扩大评审和回归范围。
- 修改 localStorage 键名或结构但未说明兼容影响，导致历史数据丢失。
- 页面逻辑已修改但未做最小可用验证（能否打开、是否报错、核心流程是否可点击）。
- 交付说明缺失影响范围，导致后续联调时无法快速定位风险。

## 默认检查点

1. 这次改动是否只影响单个游戏目录，还是还影响首页入口或公共资源。
2. 是否存在已有模式可复用，而不是继续新增抽象。
3. 验证命令或验证步骤是否贴近本次改动。
4. 最终交付是否写清改动文件、验证结果、未覆盖风险和影响范围。
