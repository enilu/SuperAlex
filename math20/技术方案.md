# 🎮 20以内加减法数学游戏设计方案

## 一、游戏概述

一个寓教于乐的儿童数学练习游戏，通过类似俄罗斯方块的视觉效果，让小朋友在趣味中练习20以内的加减法。

---

## 二、功能需求

### 2.1 游戏模式
| 模式 | 说明 |
|------|------|
| 🟢 加法模式 | 20以内的加法运算 |
| 🔴 减法模式 | 20以内的减法运算（结果非负） |
| 🟡 混合模式 | 加减法混合出题 |

### 2.2 答题模式
| 模式 | 说明 |
|------|------|
| 📝 选择模式 | 从三个选项中选择答案 |
| 🔢 填写模式 | 使用数字键盘输入答案 |

### 2.3 游戏流程
```
开始界面 → 选择答题模式 → 选择运算模式 → 游戏进行中（20题） → 结算界面 → 重新开始
```

## 三、游戏玩法设计

### 3.1 界面布局
```
┌─────────────────────────────────┐
│  🎯 分数: 85  ⏱️ 15秒  🕐 总耗时: 2分35秒 │

│                                 │
│        【当前题目区域】          │
│                                 │
│           5 + 7 = ?             │
│                                 │
│    ┌─────┐  ┌─────┐  ┌─────┐   │
│    │ 10  │  │ 12  │  │ 14  │   │
│    └─────┘  └─────┘  └─────┘   │
│                                 │
├─────────────────────────────────┤
│    📝 答题反馈区域              │
└─────────────────────────────────┘
```

### 3.2 题目移动机制
- 题目从顶部逐渐向下移动
- 移动速度适中，给孩子思考时间
- 点击答案后立即显示下一题

### 3.3 倒计时功能
- 每道题有固定答题时间（可在配置中设置）
- 顶部状态栏显示当前题目剩余时间
- 倒计时结束自动判定为答错，进入下一题
- 倒计时最后5秒显示为红色，提醒用户加快速度
- 题目从顶部逐渐向下移动
- 移动速度适中，给孩子思考时间
- 点击答案后立即显示下一题

### 3.3 答案选项设计（选择模式）
- 一个正确答案 + 两个错误选项
- 错误选项为"接近答案"的干扰项（如正确答案12，选项为10、12、14）

### 3.4 数字键盘设计（填写模式）
```
┌─────────────────────────────────┐
│           5 + 7 = ?          │
│     ┌─────────────────┐        │
│     │   [  _  ]      │        │
│     └─────────────────┘        │
│                               │
│  ┌───┐ ┌───┐ ┌───┐          │
│  │ 1 │ │ 2 │ │ 3 │           │
│  └───┘ └───┘ └───┘           │
│  ┌───┐ ┌───┐ ┌───┐          │
│  │ 4 │ │ 5 │ │ 6 │           │
│  └───┘ └───┘ └───┘           │
│  ┌───┐ ┌───┐ ┌───┐          │
│  │ 7 │ │ 8 │ │ 9 │           │
│  └───┘ └───┘ └───┘           │
│  ┌──────┐ ┌───┐ ┌───┐        │
│  │清除  │ │ 0 │ │确定│        │
│  └──────┘ └───┘ └───┘        │

```
- 0-9数字按钮用于输入答案
- 清除按钮：删除已输入的数字
- 确定按钮：提交答案进行判断

## 四、评分系统

### 4.1 分数计算
- 每题5分，共20题，满分100分
- 答对+5分，答错不扣分

### 4.2 评价等级

| 等级 | 分数段 | 星级 | 鼓励话语 |
|------|--------|------|----------|
| 🌟 优秀 | >90分 | ⭐⭐⭐ | 太棒了！你真是数学小天才！继续保持！ |
| 🌈 良好 | >80分 | ⭐⭐ | 做得很好！再接再厉，你能更优秀！ |
| 💪 需努力 | ≤80分 | ⭐ | 没关系，多练习就会进步！加油！ |

## 七、特殊细节

1. **减法规则**：确保被减数≥减法，结果≥0
2. **干扰项策略**：错误答案与正确答案相差±2以内
3. **防误触**：题目出现后0.5秒才可点击
4. **倒计时设置**：可在配置中设置每题答题时间（秒），默认15秒
5. **超时处理**：倒计时结束自动判为答错，计入错误次数
6. **进度保存**：可扩展本地存储最高分

## 八、音效文件说明

游戏需要以下音效文件，请将MP3文件放置在 `sounds/` 目录下：

| 文件 | 用途 | 推荐风格 |
|------|------|----------|
| `sounds/good.mp3` | 答对音效 | 欢快、愉悦的提示音（如"真棒"、"太好了"） |
| `sounds/comeon.mp3` | 答错音效 | 温馨、鼓励的提示音（如"加油"、"再试试"） |

> **注意**：如果音效文件不存在，游戏仍可正常运行，只是不会播放声音。浏览器可能会阻止自动播放音频，用户需要先与页面交互（如点击）后才能播放音效。
